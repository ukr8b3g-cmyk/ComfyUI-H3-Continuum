ComfyUI-H3-Continuum 3.9.1 — V3.9 / V3.8X2 インストール

3.9.1はV3.9の安定化修正版です。旧v5 Takeと履歴は読めますが、新しいv6生成の前半には再利用できません。新規Full VideoまたはStart again from Chunk 1で開始してください。新しいGitHub Release／Registry公開は別工程で、過去のRelease／tagは残します。V3.8X2 WorkflowをV3.9へ自動変換せず、別々のWorkflowとして保存してください。保存済みRun／Takeも自動移行しません。

1. ComfyUIを終了します。
2. 既存の `ComfyUI-H3-Continuum` を更新する場合は、作業中のworkflowとRun Storageを先に退避します。
3. ZIPを展開し、`ComfyUI-H3-Continuum` フォルダーを `ComfyUI/custom_nodes/` に配置します。
4. ComfyUIを再起動します。旧UIが残る場合はブラウザをハードリロードします。

インストール先は、使用しているComfyUIの `custom_nodes/ComfyUI-H3-Continuum/` です。

PowerShellによる自動インストール:
`install_windows.ps1`

現行ソースの登録IDは計12件です。以下の旧V3.8基本7件（旧Audio／Video Loader 2件を含む）に、Reference Images、Decode Cache Helper、Video Adapterを加えたV3.8X2の10件と、V3.9 Sampler／Reference Images V3.9の2件です。旧Audio／Video Loaderは新規Workflowでは推奨しません。

- H3 Continuum Sampler V3.8
- H3 Continuum Reference Audios
- H3 Continuum Finalize
- H3 Continuum Load Image
- H3 Continuum Load Audio
- H3 Continuum Load Video
- H3 Continuum Second Pass

V3.8X2公式Workflowの標準経路は、Sampler V3.8 → Decode Cache Helper → Finalize → Core Create Video → Core Save Videoです。V3.9公式はSampler V3.9とReference Images V3.9ヘルパーを使用し、残りの出力経路は同様です。Hi-Res Fixは標準経路に含みません。サイズは `Size Source = First Image`（初期画像がある場合）または `Manual`（Width / Heightを入力）で指定します。

Workflowは `examples/workflows/MiniMax_H3_Continuum_V39.json` と `examples/workflows/MiniMax_H3_Continuum_V38X2.json` を別々に用意し、Templatesにも2件表示します。V3.8X2標準ZIPには両JSONを同梱し、V3.9単独ZIPも残します。ZIPはWorkflow用で、カスタムノード本体のインストーラーではありません。V3.9公式はユーザー指定JSONを無改変で採用した32ノード／39リンク、First Image＋Draft 0.30 MP、2×10秒のGenerate Full Video（保存値はFull Run）です。First Image Loaderは有効なので、Queue前に自分の画像を選んでください。Reference-onlyならFirst ImageをOFFにし、Size SourceをManualへ切り替えます。保存済み480×640はManual時のみ有効です。画像Loader 1～6は接続済み・初期Bypassで、7～9は必要な場合に画像Loaderを追加接続します。Sequence Promptは空欄なので実行前に入力してください。SpectrumとTurbo LoRAは初期OFFです。完全なgraphにはSpectrum、rgthree、KJNodesを別途導入してください。ComfyUI-Easy-Useは不要です。モデルや画像・音声は同梱しません。

最小確認:
- chunks: 2 または 3
- chunk_seconds: 5.0
- continuity: Balanced — 22 frames
- Sequence Prompt: Text (Multiline)を接続
- V3.8X2／V3.9公式Workflowでは内蔵Decode Cache Helper、Finalize、Core Create Video／Save Videoの接続を維持
- Reference Audioを複数使う場合は `H3 Continuum Reference Audios` helperへ最大3本を接続
- V3.9のチャンク別Reference Imageは `H3 Continuum Reference Images V3.9` で割り当て、Sampler V3.9へ1本接続

`pyproject.toml`の依存宣言はComfyUI >=0.32.0ですが、現行の実生成・GPU検証基準は0.34.2です。新しいV3.9テンプレートの実ブラウザー保存・再読込およびGPU受入は別Gateで、まだRelease／Registry公開を意味しません。

同一機能の旧フォルダーや旧Manager導入版を重複配置しないでください。V3.7以前のNode IDを使う保存workflowは、その対応Release/tagで開いてください。
