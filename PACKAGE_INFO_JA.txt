ComfyUI-H3-Continuum V3.5.0

MiniMax H3の5秒ChunkをAV latent contextで継続し、長尺映像として組み立てるComfyUIカスタムノードです。

V3.5.0:
- 外部加工したH3 latentをphysical group構造のまま再SamplingするSecond Pass
- Pixel/VAE round tripを使うHi-Res Fix（Experimental）
- Latent Resize utility（高倍率の直接latent補間はMain経路非推奨）
- RAM / Disk-backed / Autoを選べるAssemble + Seam V3.5
- Exact Duration、Seam、Terminal Merge、元音声passthroughを維持
- V3.4ノードと保存済みワークフローの互換性を維持

安定範囲:
- Advanced Second Pass Bridge
- Assemble + Seam V3.5のRAM / Disk-backed / Auto

Experimental:
- Main Hi-Res Fix V3.5
- Main Hi-Res Fix 3x5 2x（RTX 5060 Ti 16 GiBではTerminal 77TでCUDA OOM）

GPU受入済み:
- Main Hi-Res Fix 1x5、576から1152
- Hybrid FL2VA + Reference 1x5の統合Hi-Res FixとAdvanced Second Pass
